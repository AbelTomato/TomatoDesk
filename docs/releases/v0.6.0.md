# TomatoDesk v0.6.0

这个版本重做了收件箱的处理流程：四种状态各自分开，批量处理带撤销，邮件的已读状态开始同步回网页邮箱，还能用规则把 Dependabot、CI 这类重复通知自动收掉。

## 主要变化

- **收件箱分成四个状态**：「待处理 · 已转待办 · 已忽略 · 全部」四个 Tab，每个数字各自算出来，不再用减法拼一个「已判断」。四个状态互斥且穷尽，相加正好等于「全部」。「只看未读」从 Tab 降为行首圆点加一个筛选开关，因为它是一种阅读状态，不是处理结果。
- **批量处理与 8 秒撤销**：勾选若干条（或跨页「选择全部 N 条」）后，可以一次标为已读、标为未读、忽略或转为待办。动作执行后有 8 秒撤销窗口；撤销「转为待办」会把消息放回待处理并解除与待办的绑定，已经建好的待办保留，不会被删掉。
- **邮件已读状态同步**：在收件箱里把邮件标为已读（包括点开一封未读邮件），后台会把网页邮箱里对应的邮件也标为已读。标为未读只改本地，不会把邮箱改回未读。写入失败会自动重试，需要重新授权时在设置页「已读同步」里提示并可手动重试。
- **收件箱规则**：设置页新增「收件箱规则」。按来源、类型、发件人包含、标题包含组合条件（条件之间是「且」），把之后进来的新消息自动标为已读或忽略。保存前可以试跑，看到最近 14 天会命中多少条、其中还会改动多少条待处理；被规则处理的行带「规则」小标，不会看起来像凭空消失。
- **文案与计数整改**：界面里不再出现 `docs/` 路径、SQLite、UIDVALIDITY、游标、指数退避这类实现细节，「判断」统一说成「处理」，计数单位统一为「条」。

## 升级须知

- **数据库从 v8 升到 v9**：启动时自动迁移并备份，只加列与一张新表（规则表、处理来源、回写队列的邮件字段），旧版本应用仍能打开 v9 的数据库。
- **v0.5.0 的「只读收信」承诺到此为止**：上一版写的是「在 TomatoDesk 里点开一封邮件，网页邮箱里它仍然是未读」，从本版本起不再成立——标为已读（含点开一封未读邮件）会同步到网页邮箱。后台取信本身仍是只读方式，不会因为同步把邮件标成已读；只有你实际标了已读才会写回。
- **规则默认一条都没有**：升级不会自动处理任何消息，需要在设置页自己建。规则只对保存之后新进来的消息生效，不回改已经处理过的消息；关掉开关也不会把历史上被规则处理过的消息还原。
- **已读同步目前没有开关**：它对所有邮箱账户生效，关不掉。不想让某封邮件在网页邮箱里变成已读，就别在收件箱里标已读——「只看未读」筛选打开时点开邮件不会自动标已读。

## 安装

1. 下载 `TomatoDesk_0.6.0_x64-setup.exe`。
2. 使用同目录下的 `.exe.sha256` 校验安装包完整性。
3. 直接运行安装程序覆盖安装，无需先卸载。

安装包面向 Windows x64，需要 WebView2 运行时（Windows 10/11 通常已预装）。

## 发布资产

- `TomatoDesk_0.6.0_x64-setup.exe`：NSIS 安装程序，同时作为更新包。
- `*.exe.sha256`：安装包的 SHA-256 校验值。
- `*.exe.sig`：更新包签名，供应用内更新验签。

## 已知限制

- **标为未读不会同步到邮箱**：回写只做「加上已读」这一件事，不会把网页邮箱里已读的邮件翻回未读。
- **规则只能标为已读或忽略**：不能转待办——待办的标题需要人来确认，规则不该替你决定写什么。
- **规则只在入库时判断一次**：之后改条件、关开关都不回改已有消息；一条消息只命中按创建顺序排在最前的那条规则，不会继续往下匹配。
- **一次转为待办最多 50 条**：批量动作里只有「转为待办」有额外上限，因为它是唯一「撤销后仍留下东西」的动作；其余动作可以跨页全选。
- **不支持 Outlook / Microsoft 365**：两者已关闭基本认证，需要 OAuth2；本版本只支持授权码 / 应用专用密码登录，也不支持 NTLM。
- **只能填授权码**：QQ、163、Gmail 填登录密码会登录失败，需先在邮箱后台开启 IMAP 并生成授权码或应用专用密码。
- **不下载附件**：只保留附件名；正文为空但有附件时会写一行「含 N 个附件」的占位说明。
- **只取收件箱**：只订阅 `INBOX`，不拉取其他文件夹；不做按 `References` 的会话聚合。
- **首次窗口有限**：只回溯最近 14 天、最多 100 封，更早的历史邮件不会补拉。
- **超长邮件会截断**：单封最多读取 256 KB、正文 64 K 字符、摘要 200 字，超出部分丢弃。
- 安装包仍未进行代码签名，首次安装时 Windows SmartScreen 可能提示未知发布者；更新包的 minisign 签名只保证更新来源可信，不消除该提示。
- 仅提供 Windows x64 安装包，暂无 macOS/Linux 版本。
