# TomatoDesk v0.1.0

TomatoDesk 的首个公开版本：一个 Windows 优先、本地优先的个人信息收件箱。

## 主要功能

- **收件箱**：集中收集链接与笔记，在本机完成查看与整理。
- **快速收集**：通过全局快捷键唤起轻量收集窗口，随时记录想法和链接。
- **搜索**：在已收集的内容中快速检索。
- **GitHub 更新**：跟踪并整理 GitHub 上的更新信息。
- **本地存储**：数据保存在本机 SQLite 数据库，不上传云端。
- **系统托盘**：常驻托盘，方便随时唤起主窗口或快速收集。

## 安装

1. 下载 `TomatoDesk_0.1.0_x64-setup.exe`。
2. 使用同目录下的 `.sha256` 文件校验安装包完整性。
3. 运行安装程序，默认按当前用户安装。

安装包面向 Windows x64，需要 WebView2 运行时（Windows 10/11 通常已预装）。

## 发布资产

- `TomatoDesk_0.1.0_x64-setup.exe`：NSIS 安装程序。
- `*.exe.sha256`：安装包的 SHA-256 校验值。
- `manifest.json`：构建清单，包含版本、源码提交号与校验值。
