# TomatoDesk v0.7.0

这个版本先把随手记的保存路径改快了：保存不再等网页抓取，窗口也不会再把主界面拉到前台；链接记录终于有了能分辨的标题。检查更新从顶部横幅挪到了右下角，改成后台周期性检查。

## 主要变化

- **保存不再等网页抓取**：粘贴链接保存时，先按「站点 + 路径」写好标题与摘要并立即入库，界面显示「已保存」后 1 秒收起窗口。抓取留在后台，最多同时跑两个，连续收集不会因为某个站点慢而排队。
- **保存后不再跳到主窗口**：以前保存随手记会把主窗口带到前台，打断正在做的事；现在只收起随手记窗口。主窗口是否打开由你自己决定，下次打开时列表和角标已经是最新的。
- **链接记录的标题可读了**：`https://github.com/rust-lang/book` 这样的地址先显示为 `book · github.com`，摘要里带站点、路径和查询词（`utm_*` 这类跟踪参数会被丢掉）。网页抓取成功后，用页面标题和描述替换兜底值；抓不到就保留兜底标题，不会再出现一整列长得一样的 URL。
- **不会覆盖你改过的标题**：补全只在「标题与摘要仍是入库时的值」时才写入。你在详情里改过标题就放弃补全，后台不会把修改冲掉；补全也不更新修改时间，旧记录不会被顶到列表顶部。
- **列表只刷新那一行**：补全完成后按 id 替换对应记录，不会整页重载，翻到第几页还是第几页。
- **检查更新改成后台周期**：启动 60 秒后查一次，之后每 4 小时一次。自动检查安静进行，没有新版本时不留任何提示；发现新版本时右下角出现卡片，「稍后」可以收起成小胶囊（`新版本 v0.7.0 可用`），随时点开继续。
- **主窗口隐藏时用系统通知**：窗口不在前台时，新版本通过 Windows 通知告知，并在右下角留小胶囊；同一个版本只提醒一次，不会每次检查都弹。
- **顶部横幅移除**：更新提示不再占据页面顶部，也不会把正文往下推。

## 升级须知

- **数据库结构没有变化**：本版本不改表结构、不加迁移，直接覆盖安装即可，需要回退到 v0.6.0 也能打开同一份数据库。
- **历史链接记录不会自动变可读**：新规则只作用于升级之后保存的记录。已有记录想整理，先退出 TomatoDesk，再手动跑脚本：

  ```bash
  # 预览：只打印将要发生的变化，不写库、不联网
  cargo run --manifest-path src-tauri/Cargo.toml --bin backfill_capture_labels

  # 确认后写库：先用 VACUUM INTO 备份到库文件旁的 backup/
  cargo run --manifest-path src-tauri/Cargo.toml --bin backfill_capture_labels -- --apply
  ```

  脚本默认只按 URL 推导，加 `--fetch` 才会额外抓页面标题与描述。它只补空着的一侧，不动备注、正文和修改时间，所以列表顺序不变。

- **更新提示的位置变了**：从顶部横幅改成右下角卡片。同一版本提醒过一次后不再重复，想再看到需要手动检查；托盘菜单的「检查更新」仍然随时可用。
- **系统通知需要 Windows 允许**：如果关掉了 TomatoDesk 的通知权限，窗口隐藏时只会留下小胶囊，不会弹通知。
- **抓取失败不再有提示**：保存本身不受影响，失败时保留按 URL 推导的标题。想再试一次可以跑回填脚本（加 `--fetch`）。

## 安装

1. 下载 `TomatoDesk_0.7.0_x64-setup.exe`。
2. 使用同目录下的 `.exe.sha256` 校验安装包完整性。
3. 直接运行安装程序覆盖安装，无需先卸载。

安装包面向 Windows x64，需要 WebView2 运行时（Windows 10/11 通常已预装）。

## 发布资产

- `TomatoDesk_0.7.0_x64-setup.exe`：NSIS 安装程序，同时作为更新包。
- `*.exe.sha256`：安装包的 SHA-256 校验值。
- `*.exe.sig`：更新包签名，供应用内更新验签。
- `latest.json`：更新清单，指向被标记为 Latest 的 Release。
- `manifest.json`：构建清单，包含版本、源码提交号与校验值。

## 已知限制

- **抓取范围有限**：只读 HTML 的头部与正文首段，5 秒超时、512 KB 上限、最多跟随 5 次重定向，非 HTML 内容直接放弃。需要登录、有反爬或只返回 JSON 的页面抓不到元数据，标题会一直是按 URL 推导的兜底值。
- **补全只尝试一次**：入库后那一次抓取失败就不会再重试，退出应用重进也不会补；需要补齐得跑回填脚本。
- **标题与摘要会截断**：标题最多 160 字、摘要最多 240 字，路径只取最后三段、查询参数只取前三个非跟踪字段。
- **同一个链接保存两次仍是两条记录**：随手记不做去重，两次保存会得到两条独立记录，补全各写各的。
- **开发版与正式版数据不互通**：用 `pnpm tauri:dev` 启动的开发版使用独立的数据目录、凭据与热键，可以和正式版同时运行，但看不到正式版里的数据。
- 安装包仍未进行代码签名，首次安装时 Windows SmartScreen 可能提示未知发布者；更新包的 minisign 签名只保证更新来源可信，不消除该提示。
- 仅提供 Windows x64 安装包，暂无 macOS/Linux 版本。
