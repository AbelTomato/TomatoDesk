# TomatoDesk v0.2.0

这个版本补齐了升级通道：TomatoDesk 现在可以自己发现并安装新版本，不需要再手动去 GitHub 找安装包。

## 主要变化

- **应用内更新**：启动约 8 秒后在后台检查新版本，发现更新时在顶部显示版本号与更新说明。下载和重启都由你确认，不会打断正在使用的快速收集窗口。
- **跳过版本**：可以选择「跳过此版本」，之后不再重复提示同一个版本。
- **托盘入口**：托盘菜单新增「检查更新」，随时手动检查。
- **更新包签名校验**：每个更新包都用 minisign 私钥签名，客户端用内嵌公钥验签。签名不匹配的包会被拒绝安装，防止更新通道被投毒。
- **发布资产新增**：`latest.json`（更新清单）与 `*.exe.sig`（更新包签名）。

## 安装

首次从 0.1.0 升级需要手动安装一次：

1. 下载 `TomatoDesk_0.2.0_x64-setup.exe`。
2. 使用同目录下的 `.exe.sha256` 文件校验安装包完整性。
3. 直接运行安装程序覆盖安装，无需先卸载。

**从 0.2.0 起，后续版本会通过应用内更新推送**，无需再手动下载。

安装包面向 Windows x64，需要 WebView2 运行时（Windows 10/11 通常已预装）。

## 发布资产

- `TomatoDesk_0.2.0_x64-setup.exe`：NSIS 安装程序，同时作为更新包。
- `*.exe.sha256`：安装包的 SHA-256 校验值。
- `*.exe.sig`：更新包签名，供应用内更新验签。
- `latest.json`：更新清单，指向被标记为 Latest 的 Release。
- `manifest.json`：构建清单，包含版本、源码提交号与校验值。

## 已知限制

- 安装包仍未进行代码签名，首次安装时 Windows SmartScreen 可能提示未知发布者。更新包的 minisign 签名只保证更新来源可信，不消除该提示。
- 仅提供 Windows x64 安装包，暂无 macOS/Linux 版本。
- 更新通道为单通道，暂不支持灰度或回滚到旧版本。
- 0.1.0 没有内建更新器，无法自动收到本版本，必须手动安装一次。
