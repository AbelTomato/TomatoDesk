# TomatoDesk v0.3.0

这个版本把 TomatoDesk 从「一条时间线」改成「按仓库组织的工位」：GitHub 的 PR、Issue、Release 归到各自仓库下，「收集」只留你自己的笔记与链接。顺带重做了整套视觉，列表与详情各滚各的。

## 主要变化

- **仓库工作区**：新增「仓库」页，按仓库查看 Pull Requests、Issues、评审、Release 与自己挂在该仓库下的条目。每个仓库有概览页，可编辑自定义描述与备注，也可单独同步或「加载历史」拉全量。
- **PR / Issue 详情页**：列表行 → 右侧概览 → 完整详情页三级。概览只放摘要与关键信息，点「查看详情」进入完整正文、元信息与变更规模；返回时列表的选中项、筛选和滚动位置都还在。
- **两栏各自独立滚动**：此前窗口内容一长就是整页滚动，左右两栏会一起动。现在外壳锁死视口高度，列表与详情各滚各的。
- **界面重做**：中性 oklch 色板、五档字号、列表去卡片化；颜色只用在状态标记、提示条竖线与错误文字上。暗色为默认，跟随系统切换到浅色。
- **加载更快**：首屏只取 50 条，滚动到底再增量加载，正文按需拉取。两千条规模下首屏不再卡。
- **文案**：GitHub 原生概念沿用英文原文（`open` / `draft` / `merged` / `closed`、`review requested`、`pre-release`），自有概念用中文。

## 升级须知

- 首次启动会把数据库迁移到 v3。**迁移前会自动备份**到数据目录下的 `backup/`。
- 迁移会清理「收集」里旧的 GitHub 条目——这些内容现在归到仓库页了。升级后请到「仓库」页点一次「同步全部」，内容会重新拉回来；个人笔记与链接不受影响。
- 已经在 0.2.0 的用户会通过应用内更新收到本版本，无需手动下载。仍是 0.1.0 的用户需要手动安装一次。

## 安装

1. 下载 `TomatoDesk_0.3.0_x64-setup.exe`。
2. 使用同目录下的 `.exe.sha256` 校验安装包完整性。
3. 直接运行安装程序覆盖安装，无需先卸载。

安装包面向 Windows x64，需要 WebView2 运行时（Windows 10/11 通常已预装）。

## 发布资产

- `TomatoDesk_0.3.0_x64-setup.exe`：NSIS 安装程序，同时作为更新包。
- `*.exe.sha256`：安装包的 SHA-256 校验值。
- `*.exe.sig`：更新包签名，供应用内更新验签。
- `latest.json`：更新清单，指向被标记为 Latest 的 Release。
- `manifest.json`：构建清单，包含版本、源码提交号与校验值。

## 已知限制

- 安装包仍未进行代码签名，首次安装时 Windows SmartScreen 可能提示未知发布者。更新包的 minisign 签名只保证更新来源可信，不消除该提示。
- 仅提供 Windows x64 安装包，暂无 macOS/Linux 版本。
- 仓库同步覆盖元信息、README、PR、Issue 与 Release；不含 Discussions、Actions 与评论正文，评论只统计条数。
- 增量同步只看最近改动，更早的历史内容需要手动点「加载历史」。
- 详情页正文按纯文本展示，不渲染 Markdown。
