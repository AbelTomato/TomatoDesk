# TomatoDesk v0.4.0

这个版本让 PR / Issue 详情页真正能读：正文按 GitHub 的语义渲染 Markdown，评论也会按需拉取、缓存并同样渲染。此前正文是一整块等宽纯文本，`##`、表格和代码围栏都按字面量显示。

## 主要变化

- **正文渲染 Markdown**：标题、列表、任务列表、表格、围栏代码块、引用、链接、图片、脚注与自动链接都按 GitHub 的样式呈现；单个换行也按 GitHub 语义换行，不再把「一行一句」挤成一段。
- **评论可以看了**：打开详情页时按需拉取该 PR / Issue 的对话评论，先显示本地缓存，再在后台刷新。评论区支持手动刷新，离线或未配置 Token 时退回缓存并提示，不影响正文阅读。
- **评论本地缓存**：评论随详情一起落库，重复打开不再重复请求；GitHub 侧删掉的评论会在下次同步时从本地移除。
- **安全边界**：渲染不产生 `innerHTML`；原始 HTML 经白名单过滤（保留 `details` / `summary` / `kbd` 等，剥离 `script`、`iframe`、`form` 与所有事件属性）；链接只放行 http(s) / mailto，图片只放行 https，外链统一交给系统浏览器打开。
- **样式一致**：Markdown 排版复用现有的五档字号与中性色板，暗色 / 浅色自动跟随；代码块与宽表格各自横向滚动，不撑破两栏布局。

## 升级须知

- 首次启动会把数据库迁移到 v4，只新增评论表与 `comments_synced_at` 列，不改动既有数据；**迁移前仍会自动备份**到数据目录下的 `backup/`。
- 评论默认按需拉取，不会在同步时批量请求，因此第一次打开某个 PR / Issue 的详情时可能看到短暂的加载状态。
- 已经是 0.2.0 及以上的用户会通过应用内更新收到本版本，无需手动下载。

## 安装

1. 下载 `TomatoDesk_0.4.0_x64-setup.exe`。
2. 使用同目录下的 `.exe.sha256` 校验安装包完整性。
3. 直接运行安装程序覆盖安装，无需先卸载。

安装包面向 Windows x64，需要 WebView2 运行时（Windows 10/11 通常已预装）。

## 发布资产

- `TomatoDesk_0.4.0_x64-setup.exe`：NSIS 安装程序，同时作为更新包。
- `*.exe.sha256`：安装包的 SHA-256 校验值。
- `*.exe.sig`：更新包签名，供应用内更新验签。
- `latest.json`：更新清单，指向被标记为 Latest 的 Release。
- `manifest.json`：构建清单，包含版本、源码提交号与校验值。

## 已知限制

- 安装包仍未进行代码签名，首次安装时 Windows SmartScreen 可能提示未知发布者。更新包的 minisign 签名只保证更新来源可信，不消除该提示。
- 仅提供 Windows x64 安装包，暂无 macOS/Linux 版本。
- 评论只覆盖 PR / Issue 的对话评论，不含代码行级 review comments；首次拉取按 GitHub 分页取全量（每页 100 条），评论特别多的对话首次打开会慢一些，之后走本地缓存。
- Markdown 不做语法高亮、Mermaid 与数学公式渲染，`@user` 与 `#123` 保持纯文本；标题与概览摘要仍为纯文本（与 GitHub 网页端一致）。
- 详情页正文按需拉取，离线时只能看到已缓存过的正文与评论。
